# FreeDNS Filters

A reference of **FreeDNS domains** and their observed accessibility across various web filtering, content filtering, surveillance, DNS filtering, firewall, and network security platforms.

The purpose of this repository is to document and compare how different filtering systems classify, allow, restrict, or otherwise handle domains associated with FreeDNS services. This information is intended for **research and educational purposes**.

## Purpose

Many organizations, schools, workplaces, public networks, and internet service providers use filtering technologies to enforce acceptable use policies, security controls, or regulatory requirements. FreeDNS domains may be treated differently across these systems due to differences in categorization databases, threat intelligence feeds, policy configurations, or vendor-specific filtering logic.

This repository aims to:

- Catalog known FreeDNS domains and subdomains.
- Record accessibility observations across filtering products and services.
- Compare categorization and blocking behavior between vendors.
- Provide a historical reference for researchers and administrators.
- Improve transparency regarding filtering decisions and classifications.
- Support testing and validation of network security configurations.

## Scope

The repository may include information regarding:

- FreeDNS root domains
- Publicly available FreeDNS subdomains
- DNS categorization results
- Filtering status across platforms
- Historical accessibility changes
- Vendor classification differences
- User-submitted observations and verification reports
